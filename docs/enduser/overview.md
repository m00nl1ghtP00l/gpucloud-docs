Typical end users are data scientists, ML researchers or developers. Once the tenant's "Org Admin" assigns the user with the appropriate end user role, they will have the ability to login into the self service portal. Upon successful login, the end users are taken directly to the self service portal (aka Developer Hub). This self service provides a unified interface for end users to manage AI/ML workflows efficiently. With this portal, end users can:

- Organize their resources using Workspaces
- Configure, Deploy and Use Compute Resources (i.e. Bare Metal Servers, Virtual Machines, Kubernetes Clusters etc.)
- Configure, Deploy and Use Applications and Tools (i.e. Jupyter Notebooks, Inference Servers, MLOps Platforms etc.)
